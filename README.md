## Tech

C# · Windows Forms · .NET Framework 4.8 · SQL Server (`System.Data.SqlClient`)

## How to run

1. Open the project's `.sln` in **Visual Studio 2022**.
2. Create the database in SQL Server and update the connection string in the code.
3. Press **F5**.
